The winning article is not selected merely because it says “VPN”. It wins because its section matches the error, application, trigger, symptoms, and actual resolution steps.

KB-312 → Error 812 → Password Change

Resolution:
1. Open Windows Credential Manager.
2. Remove the saved VPN credentials.
3. Restart GlobalProtect.
4. Reconnect using the new password.

Confidence model

Confidence is not “the LLM feels 96% sure”. It is an evidence score calculated after retrieval, reranking and solution validation.
